# IntuneAppFactory
IntuneAppFactory is a set of PowerShell scripts used in an Azure DevOps Pipeline to detect, download, package and publish onboarded applications as a Win32 application to Intune, to ensure the latest version of onboarded applications are available in Intune.

## Getting started
See [docs/Setup.md](docs/Setup.md) for the app registration, Azure resources, agent pool and variable groups the pipeline needs, and for how to onboard an application.

Changes per release are listed in [ReleaseNotes.md](ReleaseNotes.md).
